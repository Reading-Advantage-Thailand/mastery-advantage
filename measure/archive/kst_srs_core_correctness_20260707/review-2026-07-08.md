## 4. Risks or blockers

- **Unratified pedagogical constants:** `H` mapping `{low:5, medium:15, high:30}`, `trendThreshold=3`, and the backlog suppression policy were not reviewed by a human curriculum expert. These directly affect learner-facing behavior.
- **Surmise closure scope:** Restricting inferred mastery to hard edges only is a deliberate design choice, but it may surprise domain authors who treat soft prerequisites as logically necessary.
- **No runtime validation:** The deliverable is specification text only. Consuming implementations still need to implement, test, and migrate.
- **Spec drift:** Multiple in-flight tracks touched the same root `SPECIFICATION.md` file in the same 24-hour window. While the final commits claim a consistency sweep, the compressed timeline increases the chance of overlapping edits in shared sections (e.g., §12.7 was modified by both core and planner tracks).
